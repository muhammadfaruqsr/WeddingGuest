Catatan Keamanan

  • PIN diperiksa di browser (disimpan sebagai hash PBKDF2), bukan di server. Ini pembatas akses biasa, bukan pengaman setingkat server.
  • Video tersimpan di penyimpanan browser tablet ini. Siapa pun yang dapat membuka profil browser atau DevTools pada tablet dapat mengaksesnya tanpa PIN.
  • Dashboard tidak ditautkan dari layar tamu; alamatnya hanya admin.html.
  • Sesi otomatis terkunci setelah 10 menit tanpa aktivitas.
  • Cadangkan video secara berkala dengan tombol Unduh.

Status Aplikasi & Offline

Pemeriksaan ini hanya membaca kondisi perangkat ini. Hasil "Siap offline" baru terbukti setelah Anda mengujinya dengan mode pesawat.

Catatan Offline

  • Aplikasi dan font disimpan di Cache Storage; video tamu tidak pernah masuk Cache Storage — tetap di IndexedDB.
  • Memperbarui versi aplikasi hanya mengganti cache. IndexedDB (video, intro, nama pengantin, PIN) tidak disentuh.
  • Versi baru diaktifkan otomatis di layar tamu hanya saat sedang idle di layar sambutan.
  • Menghapus data situs/aplikasi lewat pengaturan Chrome atau Android akan menghapus video. Unduh cadangan secara berkala.
  • Jika tombol Pasang tidak muncul, gunakan menu ⋮ Chrome → Instal aplikasi / Tambahkan ke layar utama.
